# Provisional rubric notes

Scores are 1–5 unless the course policy overrides:

| Score | Meaning |
| ---: | --- |
| 5 | Accurate, cites the code/decision, discusses tradeoffs |
| 4 | Solid with minor gaps; evidence present |
| 3 | Partial; some concepts without clear code link |
| 2 | Vague or mostly incorrect; thin evidence |
| 1 | Non-answer / off-topic with some attempt |
| 0 | Only if explicitly unanswered **and** lecturer marks as such — default leave unscored with `insufficient` |

## Sufficiency

- `high` — multiple linked answers or one deep answer with clear citation
- `moderate` — one adequate answer
- `low` — short/ambiguous answer
- `insufficient` — missing answer or refused/unclear with no substance

Unanswered scheduled questions must surface as coverage warnings, not automatic zeros.
